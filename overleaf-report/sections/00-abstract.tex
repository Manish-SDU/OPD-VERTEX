\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}

This project was developed as part of the fourth semester Software Engineering curriculum. It concerns the design and implementation of OPD-Vertex, a web-based platform that supports medical consultations through recording, transcription, AI-assisted draft generation, clinician review, PDF creation, and follow-up communication.

The system is intended for doctors, patients, and administrators. It addresses the practical challenge that consultation documentation is often written manually while the consultation is still taking place. By allowing a doctor to record an ongoing consultation, process the spoken content locally, and generate editable clinical documentation, the application aims to reduce administrative overhead while preserving medical responsibility with the doctor.

Rather than implementing a standalone appointment scheduling service, the project focuses on support during and after an active consultation. Healthcare providers are assumed to already use scheduling systems, and OPD-Vertex is designed so that such functionality can be integrated later as an external component.

Technically, the project reflects the semester themes of Artificial Intelligence, Component-Based Systems, Algorithms and Data Structures, and Designing Software Systems with Embedded Elements. This is demonstrated through local AI transcription and summarization, modular architecture, structured handling of consultation data, and privacy-aware processing of sensitive medical information.

\begin{summarybox}
The central result is a local-first consultation support prototype where AI assists with drafting and review, but the doctor remains responsible for editing, approving, rejecting, exporting, and sending clinical information.
\end{summarybox}
